# @gw/tokens

## 0.2.0

### Minor Changes

- Initial release of shared component library and token bridge:

  - `@gw/tokens`: Design tokens Single Source of Truth with automated adapters for Tailwind v4 (`theme.css`) and Tailwind v3 (`preset.js`).
  - `@gw/ui`: Reference component primitives (`Button`, `Input`, `Card`) with CVA styling, strict TypeScript types, dual ESM/CJS distribution, and WCAG 2.1 AA automated accessibility audits via `axe-core`.
